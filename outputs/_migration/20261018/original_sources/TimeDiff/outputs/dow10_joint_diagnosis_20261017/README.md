# 聯合條件批次：相關性、high／low 與尾部差距的原因診斷

**結論：主要問題位於模型的完整生成行為。70／30 配對取樣沒有造成這三項偏差；價格重建沒有造成相關性與尾部差距，但 clipping 把模型的 high／low 違規轉成大量 H＝C、L＝C 的價格。**

診斷的是 `dow10_joint_20261017` 的固定模型與完整 2,000 條批次。另做固定 checkpoint 的生成步數、噪音種子、單步去噪、生成鏈與完整驗證期對照。沒有跑 PPO、沒有重訓、沒有修改正式模型程式或原批次。分析完成日：2026-10-18（台灣）。

## 1. 股票間相關性：取樣提高相關性，生成變異才把它拉低

| 層次 | 逐路徑股票間平均相關性 |
|---|---:|
| 2010–2017 完整條件母體 | 0.3354 |
| 70／30 混合分布的理論加權真實路徑 | 0.3594 |
| 本次抽中條件的配對真實未來 | 0.3618 |
| TimeDiff 原始生成報酬 | 0.1864 |
| 最終價格反推的報酬 | 0.1864 |

取樣組成效應為 +0.02396，有限抽樣差異為 +0.00242；生成相對配對真實路徑的差距為 −0.17541。全部 **45 個股票配對**的平均相關性都下降，不是單一股票或特定年份主導。完整池與尾部池分開比較也都下降。

變異分解顯示，並非所有共同變動都消失：

- 股票間平均共變異為真實資料的 **1.07 倍**。
- 每日所有股票平均報酬的變異為 **1.24 倍**。
- 各股扣除當日所有股票平均報酬後的殘餘變異為 **2.19 倍**。
- 平均個股年化波動由 **21.83% 升至 30.39%**，也高於生成器 2005–2017 訓練母體的 24.46%。

因此較精確的解釋是：**個股殘餘變異膨脹得比共同變動快，稀釋了相關性**。這裡的「殘餘」是扣除每日橫斷面平均的代數分解，不是已估計出的獨立經濟因子。

同一歷史／條件四條路徑的平均軌跡相關性為 **0.3823**，各路徑減去該平均軌跡後的殘差相關性只有 **0.0491**。這支持生成的隨機變異缺少共同結構，但四條平均不是精確條件期望；也不建議把平均軌跡直接當合成資料，因為這會壓低隨機性。

**已確認的訓練設計**：目前 `lambda_cross_max=0`，組合的 R、sigma 是僅有的兩個市場條件；它們不能唯一決定 10 檔股票的共變異、個股波動或共同下跌結構。模型有跨通道卷積，不能將問題說成「模型完全不看其他股票」，也不能單憑高斯獨立噪音就認定擴散模型必然無法學相關性。

來源：[layer_comparison.csv](layer_comparison.csv)、[45 組配對](pairwise_correlation_gaps.csv)、[變異分解](replicate_covariance_decomposition.csv)、[各股波動](asset_volatility.csv)。

## 2. high／low：模型超出有效範圍，clipping 再形成邊界堆積

輸入特徵定義為 `a=log(H/C)≥0`、`l=log(L/C)≤0`。模型目前在標準化後的實數空間生成，輸出 head 沒有符號限制；兩項條件 loss 只使用收盤報酬通道，不會直接約束 high／low。

| 指標 | high | low |
|---|---:|---:|
| 原始生成特徵違規率（各 420,000 個股票交易日） | 21.68% | 21.13% |
| 違規特徵的絕對 log 幅度中位數 | 0.00462 | 0.00473 |
| 違規中，四條路徑平均特徵仍符合符號的比例 | 78.02% | 79.74% |
| 配對真實資料 H＝C／L＝C 比例 | 1.36% | 1.48% |
| 最終生成資料 H＝C／L＝C 比例 | 21.68% | 21.13% |

真實特徵有極少數浮點符號誤差，最大僅約 3.3e−16；生成違規的中位數約 0.0046～0.0047，明顯不是四捨五入問題。約八成違規發生在四條平均仍為合法符號的位置，顯示隨機變異跨越有效範圍是主要現象之一。

既有重建公式 `H=C×exp(max(a,0))`、`L=C×exp(min(l,0))` 按設計運作。它**沒有製造原始符號違規**，但會將違規值全部壓在零，形成約 21% 的 H＝C 或 L＝C。這個重建副作用會影響日內區間及依賴 high／low 的指標，不能只用「最終 OHLC 合法」判定品質合格。

來源：[high_low_support.csv](high_low_support.csv)、[noise_and_support.json](noise_and_support.json)。

## 3. 尾部占比：條件跨界誤差，而非 70／30 配額錯誤

PR30 報酬門檻是 **−0.1841%**。完整池也包含尾部，理論尾部比率為 51.00%；本次條件為 53.00%，生成後為 45.35%。

| 路徑轉移 | 條數 |
|---|---:|
| 尾部條件，生成仍在尾部 | 820 |
| 尾部條件，生成跨出尾部 | 240 |
| 非尾部條件，生成跨入尾部 | 87 |
| 非尾部條件，生成仍非尾部 | 853 |

`1,060 − 240 + 87 = 907`，淨少 153 條，即 7.65 個百分點。240 條跨出者中，166 條（69.2%）的目標距門檻不超過 1 個百分點，216 條（90%）不超過 2 個百分點。

按目標報酬分位分組，PR0–10 的尾部保留率為 **98.33%**，PR10–20 為 **86.18%**，PR20–30 僅 **55.24%**；240 條跨出者有 188 條來自 PR20–30。因此主要是**接近門檻的條件被生成誤差推過界**，不能解讀為深度下跌情境全部生成失敗。

報酬誤差標準差為 **1.984 個百分點**，平均偏差只有 **+0.119 個百分點**。即使只在統計上扣掉這個全體平均偏差，尾部占比也僅由 45.35% 升至 46.60%，仍低於 53%；單純平移報酬無法消除差距。此扣除只是診斷計算，沒有修改或重新保存路徑。

目前條件 loss 在隨機噪音層級的一步 `x0_hat` 上計算；這不同於要求整條生成鏈的最終結果符合 R、sigma。訓練日誌中加權條件 loss／diffusion loss 的比值中位數約 1.06%，但 loss 數值比不等於梯度比，不能據此斷定單純加大 lambda 就能解決問題。

來源：[tail_transitions.csv](tail_transitions.csv)、[依分位／來源／年份分組](cohort_diagnostics.csv)、[baseline_summary.json](baseline_summary.json)。

## 4. 對照排除了哪些解釋

### 價格重建沒有改變相關性或尾部分類

由最終價格獨立反推報酬，與原始生成特徵相比：21 日報酬最大差異 4.56e−8、年化波動最大差異 2.08e−7、單一路徑股票配對相關性最大差異 7.19e−6；**2,000 條路徑的尾部分類全部一致**。單獨執行 high／low clipping 時，收盤條件與相關性完全不變。

### 增加 diffusion 生成步數沒有實質改善

固定先前打散計畫的前 96 次抽樣（92 個不同歷史視窗）、每組 4 條，共 384 條。相同 checkpoint、歷史、條件及噪音下比較 20／50／100 步，另以第二個噪音種子比較 20／100 步。原始種子、20 步的輸出逐位元重現舊批次對應的 384 條路徑。

| 噪音種子 | 步數 | 相關性 | high 違規 | low 違規 | 生成尾部占比 |
|---|---:|---:|---:|---:|---:|
| 20261018 | 20 | 0.1858 | 21.26% | 21.24% | 47.92% |
| 20261018 | 50 | 0.1860 | 21.32% | 21.26% | 47.92% |
| 20261018 | 100 | 0.1856 | 21.33% | 21.25% | 47.92% |
| 20261019 | 20 | 0.1872 | 21.62% | 21.25% | 44.53% |
| 20261019 | 100 | 0.1870 | 21.66% | 21.27% | 44.53% |

子集的目標尾部占比為 55.21%，不是完整批次的 53%。兩種子下步數效果皆很小，**不支持「20 步數值近似不足是主要原因」**；仍不能據此排除其他反向取樣器或完整推論設定的影響。

### 一步去噪結果不能替代完整生成診斷

在 96 個固定條件的單步去噪中，t=99 的純噪音輸入，預測 `x0_hat` 的相關性高達 0.984、high／low 違規為零；完整生成後卻約 0.186、違規約 21%。這不代表 t=99 的一步輸出適合作為資料，它的隨機性不足，且不是完整抽樣結果。

進一步追蹤原批次第一個 batch 的 32 條路徑，`x0_hat` 的相關性沿生成鏈由約 0.987 降至最終 0.231，high／low 違規逐步累積至約 19%／20%。追蹤未改變最後結果，逐位元重現原始 32 條輸出。

因此，**只在純噪音、高 t 的單步輸出加相關性 loss 可能對錯方向施力**；要看生成中後段與最終路徑。這是對下一輪損失設計的提醒，尚非某個新 loss 已有效的證明。

### 選模指標有盲點，但尚未證明是選了錯的 checkpoint

既有程式每次僅用驗證集前 128／483 個視窗選模，目標期間涵蓋 2018-01-02 至 2018-08-02，沒有完整涵蓋 2018–2019。此次依原 DataLoader 與種子重現分數 **0.149213**，再延伸到全部 483 個視窗，整體條件 MSE 為 **0.121307**，其餘 355 個為 **0.111245**，沒有出現「擴大驗證後條件誤差惡化」的證據。

然而完整驗證的生成相關性仍為 0.1936，high／low 違規仍為 20.48%／18.40%。**僅用 R、sigma 誤差選模，確實不會篩除這些結構問題**。其他訓練步數的 checkpoint 未保存，因此本次不能量化換選模指標會改善多少。

`probes/validation_comparison.csv` 是使用相同數字種子、但未經 DataLoader 的另一條噪音流；它不是原選模分數的重現。上述選模對照以已核對原分數的 [validation_exact_comparison.csv](validation_exact_comparison.csv) 為準。

## 5. 優先改善方案

以下是下一輪應驗證的方案，這一輪沒有實作或重訓。

1. **P0：先補生成品質的評估與選模。** 固定跨完整驗證期的歷史／條件與多個噪音種子，保存候選 checkpoints。除了 R／sigma MAE，加入股票配對相關性誤差、個股波動與殘餘變異、high／low 原始違規率與邊界堆積、分位組別尾部保留率及多樣性。只用訓練／驗證期決策，保持 test 封存。完整生成結果才是評估對象。
2. **P1：優先修正跨股票隨機變異的結構與尺度。** 對共同／個股殘餘變異、共變異及各股波動一起做約束或校準，不單獨追求一個平均相關係數。先對照 generation-aligned 的短鏈或完整鏈訓練訊號，與現有一步 loss 比較；實驗中同時檢查生成中後段。若仍無法控制，再評估共同因子＋個股殘差的模型／噪音表示。這些是待驗證方案，不是已確認的修正。
3. **P1：high／low 改用符合有效範圍的表示。** 將幅度定義成 `a=log(H/C)≥0`、`b=log(C/L)≥0`，採可逆的正值幅度表示或非負輸出設計，並處理真實零值；重訓時同步調整資料轉換與尺度。重建使用 `H=C exp(a)`、`L=C exp(−b)`。不可直接對舊 checkpoint 的輸出套 softplus，因為會改變分布。評估需同時看零值比例與區間分布，不只看違規率歸零。
4. **P2：加強最終路徑的條件一致性，特別檢查 PR20–30。** 在固定 70／30 計畫下對照條件 loss 權重與施加位置，量測生成末端 R／sigma 誤差、偏差及跨界數，同時維持路徑多樣性。先使用單因素對照，再驗證組合，避免一次更動所有 loss 後無法歸因。高噪音單步誤差降低不等於最終誤差降低。
5. **暫時維持 70／30 取樣。** 目前不優先增加尾部配額、改用更極端條件、增加生成步數、平移所有報酬或事後剔除不合格路徑。這些手段無法單獨解決目前看到的結構與條件誤差，且會混入新的分布改變。

若下一輪只能先做一個模型實驗，建議選 **P1 的共同／殘餘變異與最終生成相關結構**，因為這直接影響 PPO 是否見到多股票同步風險；P0 是評估前提，high／low 的有效範圍表示則是下一個清楚且可獨立驗證的變更。

使用 TimeDiff 的 `.venv-spx/bin/python`。診斷 scripts 位於新資料夾，未修改上一批任何檔案。原始資料、checkpoint、舊批次產物與正式程式雜湊均核對。重疊視窗與同條件多條路徑並非獨立樣本，未宣稱 IID 信賴區間。步數試驗與生成鏈追蹤是小型固定對照；精確辨認 loss、模型容量、訓練時程各自的因果貢獻，仍需保存多個 checkpoint 的訓練消融實驗。
